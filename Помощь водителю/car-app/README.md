# АвтоПомощник 🚗

Веб-приложение для автовладельцев — выбор марки/модели автомобиля и доступ к инструкциям, погоде, штрафам и дорожным памяткам.

## Возможности

### Основное
1. **Выбор автомобиля** — 25 марок, 228 моделей, год выпуска
2. **Индикаторы на приборной панели** — 38 значков с пояснениями, фильтр по цвету
3. **Дорожный прогноз погоды** — Open-Meteo, текущая погода + 7 дней + советы по вождению
4. **Рекомендации по эксплуатации** — сезонные (по текущей дате) + учитывающие погоду сейчас
5. **Проверка штрафов ГИБДД** — переход на официальный сервис с подставленным госномером
6. **Заправки и сервисы рядом** — прямые ссылки на Яндекс.Карты: АЗС, газ (АГНПС), зарядные станции, шиномонтаж, запчасти, мойка, техосмотр
7. **Страхование** — калькулятор ОСАГО, оценка КАСКО, 34 страховщика, аварийные комиссары
8. **Экстренные службы** — федеральные + Челябинск, один тап на звонок
9. **Чек-лист перед поездкой** — 15 пунктов, прогресс сохраняется в браузере
10. **Сервис и ТО** — расчёт, что пора менять, по пробегу и сроку
11. **Дорожная памятка** — ДТП, комплект в авто, ограничения скорости, поломка в пути

### Инструкции по эксплуатации
11. **Поиск PDF-инструкций** — из локальной папки (Google Диск) или с сервера
12. **Прямая ссылка** на раздел руководств выбранной марки на сайте производителя

### Персонализация под выбранный автомобиль
После выбора марки и модели приложение:
- показывает карточку **«Мой автомобиль»**: тип двигателя, привод, рекомендованная вязкость масла, наличие ГУР
- **скрывает нерелевантные индикаторы** (дизельные лампы — для бензиновых, лампа полного привода — для переднего привода, лампа EPS — для механики) и помечает релевантные меткой «ваш авто»
- **подставляет мощность двигателя** в коэффициент КМ калькулятора ОСАГО
- **уточняет про ГУР** в разделе жидкостей: «жидкость не нужна» или «проверяйте уровень»
- показывает подсказку по модели в разделе «Инструкция» и в шторке-меню

База: 25 марок × 228 моделей, 123 индивидуальных переопределения
(дизель, гибрид, электромобиль, полный привод, механический ГУР).

### Мобильная адаптация (для клиентов автосервиса)
- **Нижняя панель быстрых действий** — сервис / эвакуатор / маршрут / SOS всегда под большим пальцем (единственный источник этих кнопок, дублирования на странице нет)
- **Шторка-меню** (кнопка ☰ в шапке) — все 15 разделов, сгруппированных по смыслу, + быстрые звонки внизу
- **PWA** — устанавливается на домашний экран телефона (manifest.json + apple-touch-icon)
- **safe-area-inset** — корректная работа на iPhone с вырезом
- **Шрифт в полях 16px** — iOS не зумит страницу при фокусе
- **Тач-таргеты ≥ 44px**, отключён выделение и двойной тап
- **Горизонтального скролла нет** ни на одном экране

### Кнопки быстрого вызова

## Как добавить свои PDF-инструкции

### Основной вариант — общая папка на Google Диске

Приложение ссылается на папку:
`https://drive.google.com/drive/folders/1I6sZgPnmy24GfeuA9nq0mnetHQ4SnZmK?usp=drive_link`

Кнопка **«📂 Открыть папку на Google Диске»** в разделе «Инструкция» открывает её
на телефоне (потребуется вход в Google-аккаунт). Папка приватная, поэтому
приложение не может вывести список файлов — оно подсказывает, какое руководство
искать, исходя из выбранного автомобиля.

> Чтобы список инструкций появился прямо в приложении, нужно положить PDF
> рядом с приложением (вариант ниже) либо открыть доступ «по ссылке»
> и прислать новый адрес.

### Вариант 2 — на сервере (общий доступ для всех)

1. Положите PDF-файлы в папку `manuals/`
2. Создайте в ней `manifest.json`:

```json
[
  { "name": "Kia Rio 2020.pdf", "url": "manuals/kia-rio-2020.pdf" },
  { "name": "Hyundai Solaris.pdf", "url": "manuals/hyundai-solaris.pdf" }
]
```

3. Приложение подхватит список автоматически при загрузке

## Страхование: источники данных

| Данные | Источник | Дата актуальности |
|---|---|---|
| Список страховщиков, лицензии, сайты, телефоны | Реестр ЦБ РФ `list_ssd.xlsx` | 27.10.2026 |
| КТ, КБМ, КВС, КМ, КО, КС | Указание Банка России № 7204-У | действующее |
| Коридор базового тарифа ТБ | ЦБ РФ, 2025 | 1 646 – 7 535 ₽ |
| Аварийные комиссары Челябинска | сайты avarkom74.ru, 2ГИС | проверено 27.10.2026 |

Все 34 страховщика в списке имеют **действующую лицензию** и на ОСАГО, и на КАСКО
(вид деятельности «Страхование средств наземного транспорта»).

**Формула расчёта ОСАГО:**
```
Цена = ТБ × КТ × КБМ × КВС × КО × КМ × КС
```
- ТБ — базовый тариф страховщика в коридоре ЦБ (1 646 – 7 535 ₽)
- КТ — территориальный (Челябинск 1,77; Магнитогорск 1,64; Копейск 1,48; Златоуст/Миасс 1,32; Сатка/Чебаркуль 1,16; прочие 1,00) — 51 территория
- КБМ — 15 классов безаварийности (3,92 … 0,46)
- КВС — возраст и стаж, 8 возрастных групп × 9 диапазонов стажа
- КО — ограничение круга водителей (1 / 3,16 / 1,97)
- КМ — мощность двигателя (0,6 … 1,6)
- КС — сезонность использования (0,5 … 1,0)

**КАСКО** единой формулы не имеет — в приложении даётся ориентировочная оценка
(% годовых от стоимости авто) и прямые ссылки на калькуляторы страховщиков.

## Используемые API

| Сервис | Назначение | Ключ API |
|---|---|---|
| `api.open-meteo.com` | Текущая погода и прогноз | не нужен |
| `geocoding-api.open-meteo.com` | Поиск города по названию | не нужен |
| `yandex.ru/maps` | АЗС рядом, маршруты | не нужен |
| `nominatim.openstreetmap.org` | Обратное геокодирование (координаты → город) | не нужен |
| `ipwho.is` / `ipapi.co` | Резервное определение города по IP, если геолокация недоступна | не нужен |
| `gibdd.ru/check/fines` | Проверка штрафов | не нужен (официальная форма) |

Данные о погоде и штрафах **не покидают браузер** на сторонние серверы, кроме самих
сервисов-источников.

**Определение местоположения** работает в три шага:
1. `navigator.geolocation` браузера (точные координаты)
2. при отказе — определение по IP (ipwho.is / ipapi.co)
3. при отказе — ручной выбор города из списка 62 городов России

Город определяется обратным геокодированием через Nominatim.
